# SEC-10 — System Terminology

| Term | Meaning |
|---|---|
| **LLM** | Large Language Model — the AI model used for reading, writing, summarizing, reviewing, and reasoning over approved inputs. |
| **Prompt** | Controlled instruction template used by Gaia, Atlas, Ada, Mira, Uncle Bob, or Leonidas to produce consistent outputs. |
| **RAG** | Retrieval-Augmented Generation — the system pattern where AI retrieves approved Moderta documents before producing an answer. |
| **Agent** | A focused AI workflow with a defined role, inputs, outputs, approval gates, and audit trail. |
| **Human-in-the-loop** | Required human review or approval before AI output becomes official work, Jira content, design guidance, code, or release material. |
| **Embedding** | Search representation that allows the system to find related requirements, documents, standards, and past decisions. |
| **Fine-tuning** | Optional later-stage model training on approved company examples, only after governance, evaluation, and data controls are ready. |
| **Orchestration** | The n8n and workflow layer that connects agents, Jira, Figma, Git, documentation, approvals, and reporting. |
