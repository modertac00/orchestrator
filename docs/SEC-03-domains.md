# SEC-03 — Work Domains & AI Tool Map

Each row is a future (or existing) AI capability in the ecosystem. Start with 1–2 domains, prove value, then expand.

| Domain | What humans do today | What AI can do (machine layer) | Where humans must stay |
|---|---|---|---|
| **Business research** | Industry reports, competitor scans, SWOT, opportunity sizing | Summarize sources, compare competitors, draft SWOT tables, maintain research libraries | Strategic bets, prioritization, final narrative |
| **Market research** | Surveys, personas, TAM/SAM/SOM, pricing studies | Aggregate survey data, draft personas, scenario models, trend summaries | Segment choice, positioning, go-to-market calls |
| **Finance planning** | Budgets, forecasts, unit economics, runway | Spreadsheet drafts, sensitivity tables, variance explanations, report formatting | Assumptions sign-off, board/investor messaging |
| **Business analytics** | KPIs, dashboards, funnel analysis, recommendations | SQL/query drafts, chart narratives, anomaly flags, weekly insight summaries | Metric definitions, causal interpretation, action ownership |
| **UI/UX design** | Wireframes, flows, design systems, usability | Wireframe drafts, copy variants, accessibility checks, component suggestions from design system | Brand vision, emotional design, final visual approval |
| **Branding, marketing & video content** | Brand messaging, campaign ideas, social posts, ad copy, video scripts, storyboards, content calendars | Draft campaign concepts, generate content variations, write scripts and captions, suggest storyboard frames, repurpose long content into short posts/videos, prepare creative briefs | Brand strategy, tone of voice, creative direction, legal review, final publishing approval |
| **Software development** | Architecture, coding, reviews, deployment, code quality, engineering standards | Boilerplate, refactors, docs, API stubs, code review comments, migration scripts, standards checks, linting/test guidance, development support | Architecture, security-critical paths, coding standards ownership, merge approval |
| **Test case writing & design** | Manual test cases, test plans, acceptance criteria, regression coverage, automation scenarios | Draft clear test cases from requirements/user stories, write preconditions and steps, suggest expected results, edge cases, test data, negative cases, and Gherkin scenarios | Risk-based test strategy, priority, product behavior confirmation, release sign-off |

**Operating split:** AI drafts & automates · Humans decide & approve · Together we iterate & improve.
