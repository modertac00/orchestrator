# SEC-02 — Core Principles

1. **Human-in-the-loop by default** — AI proposes; humans approve, edit, or reject before anything ships externally or to production.
2. **Human creativity in the product** — Human thinking power, judgment, and creativity shape the product experience; AI handles the machine automation layer that supports execution.
3. **Right tool for the right job** — One giant chatbot is not enough. Use focused tools (research assistant, finance modeler, UI spec generator, code assistant, test designer).
4. **Traceability** — Every AI output should cite sources, inputs, and prompts so humans can verify.
5. **Company context first** — AI must use your product docs, brand guidelines, financial assumptions, and codebase — not generic internet answers alone.
6. **Measure and improve** — Track time saved, error rate, and human edit distance; use that to tune prompts and workflows.
7. **Security and privacy** — Customer data, financials, and proprietary code stay in controlled environments (private models, VPC, or enterprise AI APIs).
